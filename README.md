# zethi
app de cartaSethi es una web app de mentoría de vida personalizada que cruza tres capas — arquetipos junguianos, astrología y numerología pitagórica — mediante Inteligencia Artificial. El usuario completa un test de 12 preguntas, recibe su Sello Cósmico único y conversa con un mentor IA que adapta cada consejo a su perfil psicológico.
